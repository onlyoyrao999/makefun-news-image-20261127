A program that writes one image summing up 27 November 2026 world news: tankers mined off Oman as the Gulf war widens, Zelenskyy telling the BBC the US is too focused on the Middle East, Houthis advancing on Aden, a Thanksgiving storm flooding the US, Sanofi sealing a $41bn buyout of Insmed, and Bitcoin holding $60,000 amid record outflows.

## Run it

```sh
python3 main.py
```

The program copies the shipped `entry.png` (1024x1024, under 1 MiB) to `/output/entry.png` (or `$MAKEFUN_OUTPUT`), byte for byte. `draw.py` is the script that drew the front-page image with PIL.
